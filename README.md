# packagegate — 供应商离线交付压缩包入库工具

`packagegate` 在把供应商交付的 ZIP 包发布到本地目录之前，先核对清单、文件内容与
路径安全。只有全部检查通过后才创建最终目录；任何失败都会清理临时解压内容，不会留下
半份交付，也不会改动已存在的目标路径。

仅使用 Go 标准库，不依赖任何在线服务。

## 清单格式

ZIP 根目录必须有且仅有一个 `manifest.json`，清单本身不在文件列表中：

```json
{
  "files": [
    {
      "path": "reports/q3.txt",
      "size": 19,
      "sha256": "ade1917ac3ddb959fe167d2b91512aee2b8892573ae66ac10a0a802755146f14"
    }
  ]
}
```

- `files` 必填，可为空数组（允许没有数据文件）。
- `path` 为相对路径，仅允许英文字母、数字、`.`、`_`、`-` 和 `/`。
- `size` 为非负整数原始字节数；`sha256` 为 64 位十六进制 SHA-256 摘要。
- 每个数据文件必须恰好对应一个普通文件 ZIP 条目；不允许漏列、多列、重复声明、额外
  条目，也不允许清单中出现未知 JSON 字段。

### 路径安全规则

以下情况一律拒绝：

- 绝对路径、反斜杠、冒号、空路径段。
- 单独的 `.` 或 `..` 路径段（任何越界写法）。
- 本机（Windows）非法文件名，如 `CON`、`LPT1`、以点结尾的名字。
- 忽略大小写后重名（如 `Data/a.txt` 与 `data/A.txt`）。
- 文件路径与其子路径冲突（如同时声明 `a` 和 `a/b.txt`）。
- 显式目录条目、符号链接和其他特殊条目；只接受普通文件。

## 校验流程

1. 目标父目录必须已经存在；目标路径必须尚不存在（文件或目录都拒绝），且不做任何改动。
2. 打开并读取 ZIP 中央目录，校验条目数不超过 `-max-entries`（含清单自身）。
3. 校验条目类型与路径，确认恰好一个根 `manifest.json`。
4. 依据压缩头声明的解压大小做预算预检，再边解压边累计实际字节；总计超过
   `-max-bytes`（含清单自身）立即终止，绝不先无界解压再检查。
5. 逐文件对**实际解压字节**计算长度与 SHA-256，与清单逐一核对；ZIP 自身的 CRC
   完整性在读取时一并校验（不信任清单或压缩头声明的长度）。
6. 全部通过后，在目标父目录下创建临时暂存目录写入文件并再次复核落盘摘要，最后用一次
   原子重命名发布为最终目录。失败则删除暂存目录，最终目录不会被创建。

## 运行方式

```sh
go build ./...

go run ./cmd/packagegate \
  -zip delivery.zip \
  -target ./delivered/pkg-001 \
  -max-entries 10000 \
  -max-bytes 1073741824
```

- 成功：向标准输出打印 JSON 回执，退出码 0。
- 失败：向标准错误打印原因，退出码非零；目标位置及位置外均不留文件。

回执中的文件按路径排序，因此相同包的回执不受 ZIP 内部条目顺序影响；数据文件数与总字节
数都不含 `manifest.json`：

```json
{
  "target": "delivered/pkg-001",
  "file_count": 1,
  "total_size": 19,
  "files": [
    {
      "path": "reports/q3.txt",
      "size": 19,
      "sha256": "ade1917ac3ddb959fe167d2b91512aee2b8892573ae66ac10a0a802755146f14"
    }
  ]
}
```

## 构造示例包

辅助工具会遍历源目录，为每个普通文件计算长度与摘要，并生成合规的 ZIP：

```sh
mkdir -p sample-src/reports
printf 'quarterly report' > sample-src/reports/q3.txt

go run ./cmd/make-sample-package -src sample-src -out delivery.zip
```

## 测试

```sh
go test ./...
```

测试覆盖：成功入库、空清单、摘要不符、实际长度不符、路径越界与非法文件名、忽略大小写
重名、文件/子路径冲突、漏列文件、多列条目、重复声明、目录与符号链接条目、条目数与解压
字节上限、压缩数据 CRC 损坏、已有目标（目录/文件）保护、父目录缺失，以及回执与 ZIP 条目
顺序无关。
